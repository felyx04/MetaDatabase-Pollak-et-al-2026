# MetaDatabse-Pollak-et-al-2026
Code to generate figures and perform analysis of the manuscript _"Glacial and interglacial intensities across the Mid-Pleistocene Transition from a new 1.5 Myr long compilation of marine and terrestrial records"_ in Climate of the Past, Pollak et al. 2026. 

## Note:

`Figures/Data/all-data.csv` is a large file and had to be stored via LSF. When the repository is downloaded as a .zip file, `all-data.csv` is not correctly downloaded. There are two ways to circumvent this issue:

(i) download `all-data.csv` directly: i.e. go into the `Figures/Data/` folder, then click directly on the `all-data.csv` file and then click on the '_download raw file_' button

(ii) clone the repository instead of downloading the zip file: `git clone https://github.com/felyx04/MetaDatabase-Pollak-et-al-2026.git`
